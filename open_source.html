Open-Source Credits

The SEG-Y Co-render Tools load no outside code: everything, including the 3D view, is written in the HTML files themselves. They do include colour maps and colour palettes created by other people, listed here with their licences. Thank you to everyone below.

Methods (written for these tools, no code copied)

  • Colour conversions follow the sRGB (IEC 61966-2-1) and CIE L*a*b* standards, with the conversion constants used in scikit-image, so the colours match our Python tools.
  • Light smoothing is a Gaussian filter (σ 0.5) that matches SciPy's gaussian_filter.
  • SEG-Y reading follows the SEG-Y standard of the Society of Exploration Geophysicists.
  • The 3D view uses the browser's built-in WebGL.
